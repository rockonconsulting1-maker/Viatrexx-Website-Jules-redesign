# Optimization Memory - Day 2026-02-12

## Learnings
- **Nuxt Static Exports:** Editing static HTML files generated by Nuxt requires also updating the `__NUXT_DATA__` (or `unhead:payload`) script tags to prevent JavaScript hydration from reverting changes to titles, descriptions, and image sources.
- **Image Optimization:** Converting to WebP with `Pillow` (quality 80) yields significant savings (up to 85% for some assets) while maintaining visual quality.
- **Pathing:** For static sites, it is best to use absolute-from-root paths (e.g., `/assets/...`) rather than including the `public/` directory in the URL, as `public` is usually the web root.
- **CDN Redundancy:** Multiple versions of Tailwind or FontAwesome are common in mirrored sites; removing them reduces blocking requests and CSS parsing time.
