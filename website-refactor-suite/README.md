# Website Refactor Suite

This repository contains a suite of AI agent skills designed to automate the process of auditing, redesigning, and rebuilding legacy websites into modern, high-quality web applications.

## Directory Structure
- `skills/`: Contains the specialized agents.
  - `site-architecture-auditor/`: Information architecture and URL structure.
  - `ui-ux-design-system-auditor/`: Design system extraction and normalization.
  - `code-quality-refactor-auditor/`: Codebase health and React best practices.
  - `component-consistency-builder/`: UI component library generation.
  - `website-rebuilder-orchestrator/`: End-to-end assembly and validation.
  - `content-copy-consistency-agent/`: Copywriting and messaging alignment.

## Getting Started
Each skill can be added to your project using the `agent-skills` CLI or by referencing the `SKILL.md` files.
